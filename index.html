About WaW HUD Editor

An unofficial tool made for the World at War modding community.

Compose static HUD text, converted 2D materials and rectangles, then export an .inc file. Local images and screenshot backgrounds can be used for design; local HUD images need converted materials before export. Uses stock glyphs and native layout values. The preview is a composition aid; it does not reproduce every in-game shader or graphics setting.

No GSC bindings, gameplay counters, menu-screen editing or asset conversion. The export flow prepares your mod's HUD sources and images. Build the mod in Launcher, then test it in-game.

Independent of Treyarch, Activision and UGX. Built with JavaScript, Vite, Rust and Tauri. IWI wavelet decoding derives from OpenAssetTools; see ATTRIBUTION.md.

Created by phil81334.
